# A股市场行情分析指南

当用户询问A股/股市行情时，按以下步骤执行，确保输出结构化的分析报告：

## ⚡ 性能要求：并行调用
**必须一次性返回多个独立的工具调用！**
- 如果需要搜索 2 个不同关键词 → 一次返回 2 个 web_search 调用
- 如果需要抓取 2 个 URL → 一次返回 2 个 web_fetch 调用
- **不要分步调用**，每次只调用 1 个工具会严重拖慢执行速度

## 第一步：搜索实时数据（并行）
使用 `web_search` 工具**同时**搜索以下关键词（1 次调用包含所有查询）：
- `"A股 今日行情 上证指数 深证成指 创业板指"` — 获取大盘指数
- `"A股 板块热点 涨幅榜 资金流向"` — 获取板块和资金数据

## 第二步：抓取详细数据
如果搜索结果的 snippet 不够详细，用 `web_fetch` 访问搜索结果中的 URL 获取完整内容。
优先选择财经网站：东方财富、新浪财经、同花顺、雪球等。

## 第三步：编码获取（如需）
如果 web_fetch 返回 JS 渲染页面，用 `code_executor` 写 Python 脚本：
- 可用 `httpx` + `json` 访问公开 API
- 东方财富 API 示例：`http://push2.eastmoney.com/api/qt/stock/get?secid=1.000001&fields=f43,f44,f45,f46,f47,f48,f50,f57,f58,f169,f170`
- 上证指数 secid=1.000001，深证成指 secid=0.399001，创业板指 secid=0.399006

## 第四步：生成结构化报告
必须按以下格式输出分析报告：

```markdown
# 📊 A股市场行情分析报告

## 一、大盘指数
| 指数 | 最新点位 | 涨跌幅 | 成交额 |
|------|---------|--------|--------|
| 上证指数 | xxx | +x.xx% | xxxx亿 |
| 深证成指 | xxx | +x.xx% | xxxx亿 |
| 创业板指 | xxx | +x.xx% | xxxx亿 |

## 二、板块表现
### 涨幅前三板块
1. 板块名：+x.xx%，龙头股：xxx
2. 板块名：+x.xx%，龙头股：xxx
3. 板块名：+x.xx%，龙头股：xxx

### 跌幅前三板块
1. 板块名：-x.xx%，龙头股：xxx
2. 板块名：-x.xx%，龙头股：xxx
3. 板块名：-x.xx%，龙头股：xxx

## 三、市场热点
- 热点1：描述
- 热点2：描述
- 热点3：描述

## 四、资金流向
- 北向资金：净流入/出 xx 亿
- 主力资金：净流入/出 xx 亿

## 五、综合研判
基于以上数据，给出简要市场趋势判断（2-3句话）。

---
*数据来源：xxx | 分析时间：xxx*
```

## 重要规则
- 绝对不要说"我无法获取实时数据"或"建议您自行查询"
- 必须使用工具搜索和获取数据，至少尝试 web_search → web_fetch → code_executor 三级升级
- 如果某个数据点确实无法获取，在报告中标注"数据暂缺"而非省略该部分
- 报告必须包含具体数字，不能只有定性描述
